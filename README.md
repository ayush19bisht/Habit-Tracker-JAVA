# Habit Tracker JAVA 📝

A Habit Tracker web application built using Java, Spring Boot, Thymeleaf, and Maven. The project helps users create and manage daily habits efficiently through a simple dashboard interface.

## 🚀 Features

- User login page
- Dashboard for habit tracking
- Add and manage habits
- Admin panel
- Responsive UI using Bootstrap
- Spring Boot backend
- Thymeleaf templates for dynamic pages

## 🛠️ Technologies Used

- Java
- Spring Boot
- Thymeleaf
- Maven
- HTML
- CSS
- Bootstrap
- JavaScript

## ⚙️ Installation and Setup

### Clone the repository

```bash
git clone https://github.com/ayush19bisht/Habit-Tracker-JAVA.git
```

### Open project

Open the project in VS Code or IntelliJ IDEA.

### Install dependencies

```bash
mvn install
```

### Run application

```bash
mvn spring-boot:run
```

## 🌐 Access Application

After running:

```text
http://localhost:8080
```
